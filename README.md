# Paquete PIP Antonio_AHD3RA1

## Instalación 
Utilice el gestor de paquetes [pip](https://pip.pypa.io/en/stable/) para instalar
Antonio_AHD3RA1

```
pip install Antonio_AHD3RA1
```

# Uso

```
import Antonio_AHD3RA1.calculos as calculos
import Antonio_AHD3RA1.validaciones as validaciones

# Retorna un promedio al pasarle una lista o tupla
# como parametro

calculos.calcular_promedio(nota)

# Comprobar que una cadena de texto no esté vacía ni contenga
# únicamente espacios. Debe devolver True o False.

validaciones.texto_no_vacio("string")
```
